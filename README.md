# Clipper

Desktop app that finds the strongest moments in a long video and turns them into YouTube Shorts: 9:16 reframing, captions, effects, sound effects and filters, optional music, a viral-chance score, a copyright risk check, generated titles and hashtags, and scheduled uploads to YouTube.

Sources: Kick VODs, YouTube videos, or video files already on your PC (button or drag-and-drop). A file that's already Short-length is kept whole and just scored and captioned.

Live streams: paste the link of a Kick, YouTube or Twitch stream that's live right now. Clipper records it in 2-minute pieces, checks each piece for moments as it finishes, and turns the ones scoring above a threshold (Settings → Live streams) into clips straight away. It stops when you press Stop or the stream ends; old pieces are deleted as it goes, so a long stream doesn't fill the disk.

Video types: IRL, Gaming, Podcast / interview, and Film / TV reaction. Each type weighs moments differently; Podcast looks for quotable lines (hot takes, stories, numbers, advice) rather than loud reactions.

## Editing

- **Framing**: black bars, blurred background, full-screen crop, facecam + gameplay, or a **story card** (channel header, a paragraph with coloured key phrases, the video in a rounded box, a comment underneath). Crops follow the person's face as they move.
- **Captions**: meme caption, edit-page captions (coloured, glowing keywords), word-by-word pop, karaoke or clean.
- **Effects**: zoom punches, shakes, flashes, whip blurs, emoji pop-ups and an emoji ending, placed on the exact loud hits (and on the song's beat when one is chosen). Every effect can be moved, changed or removed per clip.
- **Sound effects**: built-in ones generated by Clipper (copyright-free) plus your own files in `data/sfx/mine`. Automatic effects use your sounds first, matched to the moment by file name (money sounds on money talk, fail sounds on fails, "huh"/shock sounds on surprises, booms and punches on loud hits). Any effect type can be pinned to one sound.
- **Templates**: set up one clip how you like it and press **Save as template**. Every new video is made with the default template (framing, facecam corner, captions, effects, sounds, song, filter, timeline options). Pick another one next to "Find clips", or apply one to a whole video afterwards.
- **Facecam + gameplay**: always renders split. The facecam is found automatically (the best detection in the video is reused for clips where the face isn't visible), or you pick its corner. The gameplay either fills the bottom panel or shows the whole game.
- **Colour filters**: edit look, vivid, warm, cool, cinematic, black and white, retro, deep-fried.
- **Timeline**: cuts silent pauses (jump cuts; loud action is kept) and an optional cold open that teases the payoff first.
- **Quick preview** renders a low-quality version in a fraction of the time; **Render all / Export all / Use this style for every clip** work on a whole video.
- **More title ideas** asks the connected AI for alternative titles, hooks and captions.
- **Results** shows real YouTube views for clips uploaded through Clipper next to their predicted score, and tunes the built-in algorithm to your channel once there are enough uploads.
- **Post to TikTok / Reels** exports the file, selects it in Explorer, copies the caption and opens the upload page.

## Install for someone else

Send them `Install Clipper.bat` (or tell them to download it from this repository). Double-clicking it installs Git, Python 3.11 and Node.js if missing, downloads Clipper to `%USERPROFILE%\Clipper`, installs everything, and adds a desktop shortcut. Updates: **Settings → Check for updates**.

## Setup by hand (Windows)

Needs Python 3.11 and Node.js. An NVIDIA GPU makes speech recognition much faster but isn't required.

Video encoding uses the GPU when there is one: NVIDIA (NVENC), AMD (AMF), Intel (Quick Sync), or any other GPU through Windows Media Foundation, otherwise the CPU. **Settings → Speed** shows which is in use, lets you pick one, and sets how many clips render at the same time (2 by default, which finishes a batch about a third sooner).

```
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
npm install
```

If `npm install` reports that Electron's install script was skipped, run `node node_modules/electron/install.js`.

## Run

Double-click `Start Clipper.vbs` (it opens Clipper without a console window; make a desktop shortcut to it if you like). `Start Clipper.bat` and `npm start` also work.

The first video you process downloads a speech model: about 1.6 GB with an NVIDIA GPU, or about 150 MB plus 485 MB without one. Without an NVIDIA GPU, transcription runs on the CPU and is the slow step; the progress bar shows how far along it is and the time left.

YouTube videos are downloaded in full HD in the background while the audio is analysed (roughly 300 MB per hour of video).

If something gets stuck, `data/clipper.log` records what each job did and how long it took.

## Optional keys (all entered in Settings)

- **Virality scoring** – choose the **built-in algorithm** (free, runs on your PC) or a **connected AI model**, which reads the whole transcript to pick moments and write titles, hooks and hashtags. With an AI connected, both engines work together: each proposes moments, the AI judges them all side by side, and each clip's score combines the AI's judgement, the built-in score and a bonus when both found the same moment. Cuts are extended when the biggest reaction would be cut off, and titles that only repeat a line from the speech are rewritten. Supported: Claude, OpenAI, Google Gemini, Groq, DeepSeek, OpenRouter, xAI, Ollama (local, no key), or any OpenAI-compatible service. Paste a key, press "Load models", pick one. If the AI fails, the built-in algorithm is used and the job says why.
- **Google OAuth client (Desktop app)** – needed to upload and schedule to your YouTube channel.
- **AudD key** – names the exact song playing in a clip.
- **Jamendo client ID** – ranks free music by popularity.

Everything the app stores (settings, keys, downloads, renders, exports) lives in `data/`, which is not committed.

## Copyright

The risk check is an estimate, not a clearance. Clips of other people's streams, films and shows can be claimed, blocked or struck regardless of what the app reports. Only upload what you have the right to.
